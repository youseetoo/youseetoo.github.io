Drivers

ESP32 DevKit boards (standalone, HAT+ USB-C) use a CP2102 or CH340 USB-UART chip: CP210x driver · CH340 driver. XIAO ESP32-S3 boards use native USB and need no driver.

Boot mode
  • ESP32: hold BOOT, tap RESET (EN), release BOOT.
  • XIAO ESP32-S3: hold BOOT while plugging in USB.
Common problems
  • No port in the list: charge-only cable, missing driver, or the port is open in ImSwitch / another tab.
  • Flashing stops halfway: enter boot mode manually, or erase everything and retry.
  • Test tab shows only garbage: wrong baud rate – 921600 for the HAT+ master, 115200 for standalone boards.
  • CAN satellite not found in a scan: check bus power, 120 Ω termination at both bus ends, and that no two boards share a node ID.
  • Unplugged during flashing: reconnect and flash again.
Serial protocol

One compact JSON object per line, e.g. {"task":"/state_get","qid":1}. Replies are framed by ++ / --; everything else is log output. Reference: serial commands · boards & node IDs · update satellites over CAN.
