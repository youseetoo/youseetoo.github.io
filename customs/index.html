This page prepares the XML for IAA-Plus. It does not generate the ABD itself. MRN and ABD are created by ATLAS only after the declaration has been accepted and released.

Header

Art der Ausfuhranmeldung (Procedure)

Values from the official ATLAS code list A0121. The 6th digit decides where the goods are presented (Gestellung) — and that in turn decides the Warenort codes and whether inland transport data is allowed at all.
Format for customs offices: country code + 6-digit office number, e.g. DE003004.

Dates

Auto-set: submission = now, presentation = next day 07:00, loading end = next day 13:00. Adjust if needed.

Destination and Incoterms

Requires ISO 3166-1 Alpha-2 code (2 letters). Full list →
Format: 2-letter country code + 3-letter city code (e.g. KRICN = South Korea, Incheon). Lookup UN/LOCODE →
City name of the delivery destination (matches the UN/LOCODE above).

Transport (ATLAS mask)

ATLAS rule: the first digit of „Art der Identifikation“ must match the corresponding Verkehrszweig for sea, rail, road, air and inland waterway.

Routing countries

Route #1 = departure country (always DE). Route #2 = final destination country. Route #3 = only needed when goods pass through an additional transit country on the way.

Warenort (Location of goods)

„Art des Ortes“ and „Art der Ortsbestimmung“ are derived from the Art der Ausfuhranmeldung — you cannot pick them freely. ATLAS allows only A↔V, B↔Y and D↔U/W/Z, and requires V (Zollstelle) for every code #####1##, #####3##, #####4## and #####9##.

Consignee (customer)

Products (Goods items)

Commodity code must be 8 digits (default: 90230080). Gross and net in kg. Statistical value = total invoice amount ÷ number of items.
Two-stage (00000100 / 00000200): upload the XML in IAA-Plus, wait for release/MRN, then download the ABD from ATLAS and send the PDF to the carrier.
One-stage (00000901 / 00000902): upload the XML, hand the LRN (not an ABD) to the carrier together with the goods — the ABD only arrives with the release message after the Ausgangszollstelle has taken delivery. The site prepares the XML only.
